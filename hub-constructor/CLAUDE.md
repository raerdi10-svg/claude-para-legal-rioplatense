# Perfil — Hub Constructor

> Configuración del trust gate para instalación de skills de la comunidad.

## Fuentes confiables

- `github.com/anthropics/claude-para-legal-rioplatense` — repositorio oficial
- Skills marcadas con hash fijado y firmadas por el equipo de mantenimiento

## Política de instalación

- Cualquier skill de fuente no listada requiere confirmación doble del usuario.
- Skills con acceso a herramientas de shell o escritura fuera del directorio del plugin requieren aprobación del administrador del sistema.
- Toda instalación queda registrada con: nombre de skill, fuente, fecha, usuario que aprobó.

## Directorio de skills de la comunidad

- Las skills de la comunidad se envían como PRs al repositorio oficial.
- El equipo de mantenimiento revisa el contenido antes de listarlas.
- El trust gate verifica que el hash del archivo descargado coincida con el hash publicado.

## Notas

- Este plugin no tiene CLAUDE.md de perfil de práctica propio (no es un plugin legal).
- El administrador del sistema puede agregar fuentes confiables adicionales editando este archivo.
